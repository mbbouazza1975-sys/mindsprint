# MindSprint

**Muscle tes méninges en t’amusant !** 22 mini-jeux et un grand bilan de 18 jeux en 6 catégories (calcul mental, logique, raisonnement, observation, mémoire, rapidité) avec tableau de bord et courbe d’évolution ; aussi en famille (2 à 4 joueurs sur un seul téléphone). 3 niveaux, consignes avec exemple et essai guidé sans chrono, score sur 100, étoiles et médailles, mode sombre, fonctionne hors connexion.

Application web installable (PWA), sans serveur ni compte : HTML, CSS et JavaScript simples. Les scores restent dans le navigateur.

**Jouer :** https://mbbouazza1975-sys.github.io/mindsprint/
