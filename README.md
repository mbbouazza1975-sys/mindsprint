# MindSprint

12 mini-épreuves de rapidité et de logique, à jouer seul ou en famille (2 à 4 joueurs sur un seul téléphone). 3 niveaux, records, mode sombre, fonctionne hors connexion.

Application web installable (PWA), sans serveur ni compte : HTML, CSS et JavaScript simples. Les scores restent dans le navigateur.

**Jouer :** https://mbbouazza1975-sys.github.io/mindsprint/
